# Open Questions and Sidecars

Keep a question in the primary plan with its impact, evidence already checked, temporary assumption, and status. Investigate discoverable repository facts before asking for a decision.

```markdown
- Question: <missing fact or decision>
  Impact: <what depends on the answer>
  Evidence: <sources checked>
  Assumption: <only if work can safely proceed>
  Status: <open | answered | deferred>
  Answer: <accepted decision and source when known>
```

A requested sidecar lives beside the selected plan, using the repository's existing naming. Link it from the primary artifact and identify its purpose and owner. An evidence collection can have its own format; do not create a second task ledger. A thinking sidecar means sanitized conclusions and observations, never a hidden reasoning transcript.
