# Implementation Plan Template - Superseded

This reference is superseded. `rails-plan-spam-workflow` now delegates all plan creation to the `rails-planning` skill.

Use the unified template at:

```text
skills/rails-planning/references/plan-template.md
```

That template defines the one primary artifact per story — `plan.md` — including linked context, CER, objective, scope, execution steps, validation, risk mitigation, optional phase split, and the `## Execution Log` / `## Completion Review` sections that carry the plan through delivery.

Workers dispatched by `rails-plan-spam-workflow` must follow `rails-planning` conventions and use the unified template above.
