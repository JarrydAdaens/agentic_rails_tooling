# Update Evidence and Report

Report the target and verified source, adopted profile/host, baseline schema/hash or its absence, scoped file dispositions, applied diffs, conflicts, and preserved project decisions/history. Identify missing ownership evidence explicitly.

Checks follow the affected artifact: parse the manifest and metadata where required; check relevant links and absence of unresolved generated tokens; compare saved project sections, identity, commands, and product versions; run generator regression checks when its contract is affected. Documentation updates alone do not require a product build or UI launch.

Report actual command results and limitations, including unavailable live host activation and whole-tree crash recovery. Describe any manual adoption separately from a valid automatic-update baseline. End with exact changed paths, outstanding conflicts, and commit status; no automatic commit or deployment.
