# Initialization Evidence and Report

Report selected target, verified source revision/content identity, profile and host, intake location, generated/edited files, conflicts, and unresolved facts. Separate framework generation from project synthesis.

Use observable checks: concrete generated identity, no unresolved generated tokens, relevant links resolve, documented command text matches inspected project configuration, raw intake remains, and maintained preexisting decisions survive. Count always-required instructions including imports when measuring context size; 400-800 words is a review target, not permission to delete constraints.

Run generator regression or repository validation relevant to changed artifacts. Documentation-only initialization requires no invented application build or launch. Report commands actually run, outcomes, and unavailable evidence. Host activation is a distinct live check; file presence does not prove it.

No commit, publication, or deployment is implied. Report uncommitted status when applicable and the next concrete step for unresolved conflicts.
