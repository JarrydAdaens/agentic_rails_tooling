# Outcome report

Record substantive findings beside their authoritative work item or active plan.
An external tracker item remains the status owner; link local evidence instead
of reproducing the tracker in another table.

For a blocker state the affected item, observed error, approaches tried, preserved
partial work, missing prerequisite or decision, and next useful action. Include
commands and evidence identity where relevant. Do not manufacture an experiment
or partial success to fill a template.

The final report identifies completed, partial, and blocked work; actual relevant
checks; commit SHA or verified diff identity; pending tracker delivery; and any
remaining user decision. State when the finite queue or budget ended the run.
